# Codex handoff — Project Art Impact

Base migrada para GitHub com componentes e os sete dicionários de tradução recuperados do commit Lovable `38105ef5015a11ed08d0948d3749216b591641e8`.

**Importante:** o acesso via ferramenta Lovable disponibilizou somente o diff dos dez arquivos alterados; não disponibilizou a exportação completa do scaffolding, nem as páginas internas originais. Por isso, o site neste repositório é uma **porta funcional reconstruída** em Vite + React + TypeScript + Tailwind, utilizando os componentes e conteúdos i18n originais. Não é um espelho binariamente idêntico do projeto hospedado no Lovable.

## Para continuar

1. `npm install` e `npm run build`.
2. Validar as sete rotas e os sete idiomas visualmente.
3. Substituir o wordmark provisório pelo logo oficial sem redesenhá-lo.
4. Quando necessário, comparar os arquivos com exportação/sincronização oficial do Lovable antes de fazer merge.
5. Não adicionar dados fictícios, e-commerce real ou envio de contato sem backend.
